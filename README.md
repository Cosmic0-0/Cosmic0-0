## 🚀 Things I've worked on

| Project | What it is | My part |
| --- | --- | --- |
| [FraudLens](https://fraudlens.site) | Checks suspicious messages, links or documents before payment, in English, French and Kreol Morisien. 631 backend, 99 web app and 77 add-in tests. | QA and testing, backend fixes, document forensics |
| [Travelio](https://caellumbuys.com/work/travelio/) | Live bus tracker for Mauritius covering 282 bus lines and the Metro Express. Stops show arrivals as "live" or "scheduled". 174 automated tests. | QA and bug fixes, failure handling, product and pitch |
| [AirCommand](https://github.com/Cosmic0-0/AirCommand) | Wi-Fi auditing tool that wraps aircrack-ng, hashcat and nmap. It refuses to touch any network that isn't on an allowlist of authorised targets. 22 architecture decision records. | Solo project |
| [BlueNet: Ocean Watch](https://caellumbuys.com/work/bluenet/) | Ranks suspicious vessel activity in Mauritian waters. | Team project |
| [Towards Recovery](https://caellumbuys.com/work/towards-recovery/) | Private addiction-severity screen, reviewed by a counsellor. | Team project |
| [Lantern](https://github.com/Cosmic0-0/Lantern) | Reads web novels aloud on your phone and keeps your place. | Solo project (MVP) |
